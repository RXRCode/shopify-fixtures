# v0.2 Observability & Control

The next cohesive feature batch for RXR Shopify Fixtures.

## Goals

- Add local-vs-Shopify diffing
- Make metaobject planning idempotent
- Add CI-friendly machine-readable output
- Add drift checks
- Improve diagnostics
- Improve status visibility
- Make pull selective

## New CLI surface

```text
rxr-fixtures diff
rxr-fixtures diff --json
rxr-fixtures diff --check

rxr-fixtures doctor

rxr-fixtures status

rxr-fixtures pull --resource products
rxr-fixtures pull --resource collections
rxr-fixtures pull --resource metaobjects
rxr-fixtures pull --resource all
```

## Planner actions

v0.2 evolves the planner toward:

```text
CREATE
CHANGE
SKIP
```

No delete behavior is added.

## Feature batch

### 1. Diff engine

Compare local fixture state with Shopify state.

### 2. Metaobject idempotency

Unchanged metaobjects should plan as:

```text
SKIP metaobject rxr_fixture_note/seed-42
```

Changed metaobjects should plan as:

```text
CHANGE metaobject rxr_fixture_note/seed-42
```

### 3. JSON diff output

```bash
rxr-fixtures diff --json
```

### 4. CI drift check

```bash
rxr-fixtures diff --check
```

Exit `0` when fixtures match Shopify.

Exit non-zero when `CREATE` or `CHANGE` operations exist.

### 5. Doctor command

```bash
rxr-fixtures doctor
```

Checks:

- Node.js support
- fixture directory
- fixture validity
- Shopify configuration
- authentication
- Shopify API reachability

Doctor must never mutate Shopify.

### 6. Improved status

Report:

- store
- API version
- fixture directory
- product count
- collection count
- metaobject definition count
- metaobject count
- Shopify connection state

### 7. Selective pull

```bash
rxr-fixtures pull --resource products
rxr-fixtures pull --resource collections
rxr-fixtures pull --resource metaobjects
rxr-fixtures pull --resource all
```

Default is `all`.

Selective pull must not overwrite unrelated fixture files.

### 8. Tests and documentation

Add tests for:

- CREATE detection
- CHANGE detection
- SKIP detection
- metaobject equality
- metaobject changed values
- JSON diff output
- `--check` exit behavior
- doctor
- selective pull
- status fixture counts

## Safety requirements

- no delete operations
- no destructive synchronization
- push remains plan-first
- mutation still requires `--apply`
- doctor never mutates
- diff never mutates
- status never mutates
- Shopify GIDs remain runtime-only identifiers
